# CivitaiFreeTool 扩展 2.7.0 · Chrome / Edge

## 安装 / 更新
**首次安装**：把 ZIP 解压到一个你会长期保留的固定位置（"全部提取"出来的目录名固定是 `CivitaiFreeTool-ChromeExtension`，不带版本号）。打开 `chrome://extensions`，右上角启用「开发者模式」→「加载已解压的扩展程序」→ 选中该目录。

**以后更新**：新版本 ZIP 覆盖解压到同一个目录，回到 `chrome://extensions` 点这张扩展卡片上的「重新加载」（↻）就完成升级。不用移除、不用重新选目录——manifest 里的 `key` 已把扩展 ID 与目录路径解绑，提交记录等扩展自己的存储也不会因为更新而清空。

**从 2.2.0 及更早迁移**：旧版的扩展 ID 由加载目录路径推导，2.3.0 起改用固定 ID，Chrome 会当成两个不同扩展，且同 ID 不允许并存两份未加载副本。所以这一版需要一次「移除旧条目 → 加载新目录」；扩展内的批量提交记录会重置一次，CFT 里的下载任务与历史不受影响。之后每次更新只需点「重新加载」。

## 发送当前页
先打开 CFT（推荐 v2.7.0）并在设置填写保存 Civitai API Key。点击扩展图标，在“当前页面”确认模型标题与链接，点“发送当前页到 CFT”。多文件选择在软件内完成。

## 批量标签页
1. 打开想下载的多个 C 站模型详情页，无需逐页点击扩展。
2. 打开扩展 → “批量标签页”。默认列出全部浏览器窗口的模型页，也可切换“当前窗口”。即使当前页不是 C 站，也能使用此入口。
3. 初始全选；可搜索、取消不需要的页，或用全选按钮选择当前搜索结果。
4. 点“发送选中 N 项到 CFT”。关闭小窗不打断后台提交；重新打开可查看结果。不会关闭或切换你的标签页。
5. 在 CFT 下载管理查看解析、文件选择与进度。扩展“已提交”只表示软件接收链接，不等于已下载完成。

同模型同版本同文件 ID 的 red/com 重复页合并；不同版本 / 文件保留。一次最多 500 个不同条目。
未收到确认的条目会显示“待核对”，不会自动重发。先查看 CFT；如确需再次发送，点“清除提交记录（允许重新发送）”，此操作只清扩展记录，不删除 CFT 任务。

右键模型页或模型链接 → “发送到 CivitaiFreeTool”仍可使用。

## 标签页索引（给本机 Agent 用）

后台在标签页创建/更新/关闭/移动/切换后去抖 1.2s、每分钟心跳一次，把打开的 **C 站模型页**标题、URL、模型/版本 ID 以只读索引推到本机桥 `POST /api/ext/tabs`。桌面端 `GET /api/ext/tabs` 与只读工具 `cft_browser_tabs` 可搜索这份索引，Agent 找到后可直接用 `cft_download_model` 下载，不需要模拟键鼠。索引只在内存、只含模型页，不读页面正文、Cookie、API Key 或非 C 站页面；普通网页来源会被桥拒绝。随索引上报的 `ext_version` 用于诊断版本不匹配。需要含该路由的 CFT（v2.7.0+）。

## 开发态（免打包）

本仓库开发时不要每次重新压缩/导入：在仓库根运行

```bash
python scripts/dev_extension.py link     # 已加载目录 → 指向源码的 junction（先备份，可 restore）
python scripts/dev_extension.py watch    # 改源码后自动请求重载
```

`link` 只改 `.tools/` 下的加载副本，`manifest.key` 保持不变，所以扩展 ID 与存储不变。重载在扩展下一次心跳（≤60s）或任意标签页事件后发生；**内容脚本改动仍需刷新对应页面**。发行版与用户安装方式不变，仍用 ZIP。

## 下载状态（已下载 / 有更新 / 下载中 / 未下载）

状态以桌面端 CFT 为准：模型库扫描、下载历史、活动任务队列与更新检查缓存（`model_updates.json`）合并后回答，不是只看扩展自己发过什么。扩展只把模型 ID / 版本 ID / 清洗过的页面 URL 发给本机桥，不读 Cookie、API Key 或网页正文。需要 CFT **v2.7.0 及以上**；更旧的桌面端仍可正常发送，只是状态查询会提示升级。

- **不用点图标**：后台自己把已打开的模型页批量查一遍——启动、安装/更新、以及每 2 分钟一次的心跳都会跑；点亮逐标签徽章，并把状态推给页面里已有的胶囊。一轮最多 60 个标签，跳过休眠标签与非 C 站页面，同一批 1.5 秒内不重复请求。**扩展重载后不必刷新页面**：先用一条 `ping` 探出"这个页面里还有没有接收者"，没有才把 manifest 自己声明的那几个文件注回去（只注入 `files`，绝不执行任意代码，绝不注到站外），页面里另有幂等守卫，不会被注出两个胶囊。
- **模型页胶囊**：C 站模型页右下角、归档按钮上方显示 `✓ 已下载 · v1.0`、`⬆ 有更新 · v1.0 → v1.2`、`⏳ 下载中 42%`、`◐ 已下载其他版本`、`↓ 未下载` 或 `? 状态未知`。点一下强制刷新；SPA 路由切换会重新挂载。
- **工具栏徽章**：每个模型标签页按状态显示 `✓` / `↑` / `…` / `◐` / `↓` / `?`，悬停可看本地版本、路径、最新版本与检查时间。批量归档进行中不占用这枚徽章。**没有徽章＝这一页还没判定过**（桌面端没开、缓存为空，或这个标签还没进过状态链路），与 `?`（问过但没有结论）是两回事；CFT 没开着时徽章继续显示上次已知状态并标「离线」，不会塌成 `?` 或 `↓`。
- **弹层**：行内徽章 + “下载状态”筛选 + 汇总（`已下载 3 · 有更新 1 · 下载中 1 · 未下载 4 · 未知 2`）。「只选未下载」只勾确认未下载的行，状态未知的不动。
- **下载新版**：选中「有更新」的行后出现「⬆ 下载选中项的新版（N）」，发送的是更新记录里的**最新版** URL，而不是页面里的旧版本。普通发送若命中已下载/有更新的行，会先确认再发，不静默改 URL。
- **诚实口径**：CFT 没开或模型库还没扫描完时显示「状态未知 / 上次缓存」并说明原因，绝不把“没查到”当成“未下载”。缓存 2 分钟（下载中）/ 5 分钟（其余）内有效，离线保留上次状态并标「离线」。
- **列表页 / 图片页徽章**：C 站 `/models` 列表卡片、`/images/*` 与 `/posts/*` 里的模型链接直接贴 `✓/↑/…/◐/↓`；状态未知不贴，站外/下载链接不贴。列表页查询带 `badge:false`，不会把某个模型的状态写到工具栏徽章。
- **侧边栏 / 检查更新**：标题栏「侧栏」打开常驻工作台（`chrome.sidePanel`，与弹层同一套脚本，侧栏页不自动关闭）。批量面板的「⫫ 检查这些模型的更新」只对本机模型库命中的本地文件调用桌面端 `mm_check_updates`，显示进度并在完成后刷新状态，不自动下载。
- **完成通知 / 打开目录**：提交或归档入队后，后台最多守望 2 小时；任务完成/失败/已在库时发一条通知（同一任务只发一次），按钮在文件管理器中打开 CFT 登记的落点。任务行也提供「打开目录」。桌面端只接受模型库、下载历史、活动任务里已登记的路径；未登记返回 403，不提供任意路径浏览。
- **页面历史**：「看过但未下载」只记录本机扩展里的模型页 URL/标题/时间（30 秒同标签去重、最多 500 条），可一键清除，不删下载历史或模型文件。
- **哈希识别**：补全结果里的 C 站 SHA256 会随状态请求发送；文件改名/换目录后仍可能认出同一份本地文件。文件已不存在则维持未知/未下载，不猜。

## 隐私和权限
**会注入网页**。在 `civitai.com` / `civitai.red` 的 `/models` 列表页、`/models/*`、`/images/*`、`/posts/*` 注入 content script，用于列表/页面下载状态徽章、归档按钮、当前页信息收集，以及下面第 2 条的请求通道；其它站点一律不注入。声明式注入之外还有 `scripting` 权限，**用途只有一个**：扩展重载/更新后，MV3 会把已打开标签页里的脚本一起杀掉，此时先 `ping` 探测、确认接收者没了才把上面这些**同一个 manifest 里已声明的文件**注回去，免掉"必须刷新页面"。这条路径只允许 `files`，不允许 `func`/`code`（不执行任意代码），目标只有已匹配的 C 站页面，休眠标签页不碰。

**页面请求通道**。归档评论 / 评价 / 受限样图提示词时，扩展自己发出的请求是跨站匿名的，站点因此只给空数据（tRPC 401、公开 API 返回空 items）。这时扩展会请求你已打开的 C 站标签页，**在那个页面里以同源方式代发一次 GET**，复用浏览器已有的 C 站登录会话。代发只允许 `https://civitai.com|civitai.red` 下的 `/api/v1/*` 与 `/api/trpc/*`，只读、单条响应 ≤3MB、超时即丢；响应文本只在扩展自身上下文之间传递。没有匹配的 C 站标签页或页面不应答时回落匿名直连，并把当次实际走的通道与拿不到数据的原因写进产物文本，不会假装“这个模型没有评论”。

**读取范围**：后台在标签页创建/更新/关闭/移动/切换后去抖读取标题与 URL，并每分钟心跳一次；每 2 分钟再批量查一轮已打开模型页的下载状态（一轮最多 60 个标签，只发模型/版本 ID 与清洗后的 URL）；批量归档和徽章同步期间还会按上面的 C 站 URL 规则查询标签页（用到 `tabs` 与站点 host 权限）。过滤非 C 站 URL，并移除链接里的 token / 追踪参数；只把 C 站模型页的标题/URL/模型版本 ID 推给本机桥的只读索引（仅内存），不读网页正文、Cookie、API Key 或非 C 站页面。

**发给本机软件的内容**：用户勾选的模型 URL，只读标签页索引里的 C 站模型页标题/URL/模型版本 ID，以及归档产物本身（图片、`.txt`、`example.json`、`评论.txt` 等，经 `/api/archive/file` base64 写盘）。**不发送 Cookie、API Key 或任何登录凭据**；模型文件由软件用你在 CFT 里保存的 Key 自己下载。

其它权限：`storage` 保存配置、提交记录、状态缓存与页面历史；`downloads` 只在软件写盘不可用时降级落盘，且会显式提示降级；`contextMenus` 提供右键“发送到 CFT”；`offscreen` 让归档在你关掉小窗后继续执行；`sidePanel` 提供常驻侧栏；`scripting` 只用于上面说的"把自家已声明的脚本注回已匹配的 C 站页面"，不执行任意代码、不注到站外；`notifications` + `alarms` 用于任务完成通知、后台守望（最多 2 小时，全部落地即停）、标签页索引每分钟心跳与下载状态每 2 分钟心跳。代码只连接硬编码的 `http://127.0.0.1:47531`，不访问其它本机端口；`/api/reveal` 只接受桌面端已登记的落点。
只获取此浏览器可访问的标签，不能跨 Chrome / Firefox 枚举；隐私窗口须在浏览器中明确允许扩展访问。
